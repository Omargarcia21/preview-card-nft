Este es mi solución al desafío NFT Preview Card Component de Frontend Mentor. El objetivo era crear una tarjeta responsiva que muestre la vista previa de un NFT, incluyendo detalles como el nombre, la descripción, el precio y la información del creador.

# Desafío de Frontend Mentor: NFT Preview Card Component

# Descripción del Proyecto
Este proyecto consiste en una tarjeta de vista previa de un NFT que incluye:

- Una imagen principal del NFT.
- Un título y una descripción del NFT.
- Información sobre el precio en ETH y el tiempo restante para la oferta.
- Un apartado con la imagen y el nombre del creador.
- La tarjeta está diseñada para ser completamente responsiva, adaptándose a diferentes tamaños de pantalla, desde dispositivos móviles hasta desktop.

## Tecnologías Utilizadas
- **Lenguajes de Programación:** HTML, CSS.
- **Metodologías CSS:** BEM (Block Element Modifier) para la organización del código CSS.
- **Diseño Responsivo:** Compatible con dispositivos móviles, tablets y desktop.

## Instrucciones de Instalación y Uso
Este proyecto es una página web estática, por lo que no requiere instalación.
